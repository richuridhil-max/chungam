# chungam

High-performance, scroll-driven 3D video image sequence hero section with synchronized luxury storytelling text overlays.

## Features
- **300 Ultra-HD 60fps Image Sequence Engine** powered by HTML5 Canvas.
- **Buttery-Smooth LERP Spring Damping** for Apple-grade momentum scrolling.
- **Responsive Aspect-Ratio Cover** for widescreen, laptop, tablet, and mobile devices.
- **Scroll-Synchronized Storytelling Stages** detailing haute joaillerie craftsmanship, diamonds, and gemstones.

## Running Locally
Double-click `start.bat` or run:
```powershell
powershell -ExecutionPolicy Bypass -File ./serve.ps1 -Port 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
